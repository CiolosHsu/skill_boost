# skill_boost

這是一個為期一個月的技能補強計畫，目標是快速補齊資料科學家、軟體工程師、機器學習工程師、AI 工程師四種職稱的共通缺口。  
專案分為四週，每週聚焦一個核心技能，並完成一個小型專案。

---

## 🎯 計畫目標
- 強化 SQL 與資料處理能力
- 掌握雲端與容器化技術 (Docker, Kubernetes)
- 建立 MLOps 流程 (MLflow, CI/CD)
- 學習生成式 AI 與資料可視化 (LangChain, RAG, Tableau/Power BI)

---

## 📅 四週成果

### Week 1 - SQL & ETL
- Kaggle 資料集進階查詢練習
- 建立 CSV → PostgreSQL 的 ETL pipeline
- [專案連結](./week1_sql_etl)

### Week 2 - Docker & Kubernetes
- 將 ML 模型打包成 Docker image
- 使用 Kubernetes 部署簡單 API
- [專案連結](./week2_docker_k8s)

### Week 3 - MLOps & CI/CD
- 使用 MLflow 管理模型訓練與版本
- 建立 GitHub Actions CI/CD pipeline
- [專案連結](./week3_mlops)

### Week 4 - LLM & Visualization
- 建立 LangChain + RAG demo
- 整合向量資料庫 (Pinecone/Weaviate)
- 使用 Tableau/Power BI 建立互動式報表
- [專案連結](./week4_llm_viz)

---

## 🛠️ 技術棧
- **程式語言**: Python, SQL

- **資料庫**: PostgreSQL, Pinecone/Weaviate
- **雲端/容器化**: Docker, Kubernetes, AWS/GCP
- **可視化**: Tableau, Power BI
